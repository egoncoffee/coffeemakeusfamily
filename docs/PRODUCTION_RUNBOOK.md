# Local production and review runbook

This module is a local pilot. The existing business workspace and publishing schedule stay intact until an explicit cutover. Seven roles are logical workflow components; optional model drafting stays off by default.

1. Run `egon-creative doctor`. Resolve missing Blender, FFmpeg/FFprobe, Indonesian voice and canonical-logo assets. Register the owner-provided PNG with its exact SHA-256; never take a logo from a generated poster.
2. Creative Director selects the content block using `egon-creative plan --blocks 1`: seven animated, two authentic-footage and one static item. This is a mix, not an invented daily quota. EGON is a Gen Z coffee-information media brand, with history, culture, knowledge and sourced industry insights.
3. Research and Scriptwriting prepare a schema-v1 storyboard. Real production uses `data_class=PRODUCTION`, a stable `production_id` across revisions, `language=id-ID`, a 30–60-second target, exact canonical-logo hash, named research review, opened claim-linked primary evidence and real semantic novelty comparisons against the content ledger/drafts. Do not copy the engineering fixture's novelty exemption into production.
4. Visual Director reviews the visual instructions and available scenes. The owner requested full colourful cartoon explainers after rejecting the dark pilot. Use `visual_style=cartoon_explainer_v3`, a primary action/camera/learning purpose per shot, and complete explicit shot durations summing to the episode target. The example is 44 seconds with seven shots. The bounded scene family remains coffee fruit, processing, roasting, grinding, brewing and tool/application visuals; other stories require reviewed original code/assets. A short proof is not a completed episode. Authentic-footage shots require owned registered clips and adequate duration.
5. Enqueue the reviewed JSON with `egon-creative enqueue /absolute/path/storyboard.json`, then run `egon-creative work`. One worker invocation claims one queued job. Input hashes prevent duplicate enqueueing. Different script/visual versions retain the same production ID and cumulative budget. No paid provider is called by the local worker.
6. Inspect the MP4, `QA.json`, `timeline.json`, `captions.srt`, `storyboard.json`, prompt, render logs and costs. Read-only local dashboard: `egon-creative serve --port 8765`. Technical PASS is not visual, scientific or editorial approval. Watch the entire video on a phone: hook, clarity, factual visual explanation, subtitle spelling/timing, logo fidelity, pronunciation, pace and ending.
7. Reconcile auxiliary preview or authorised external-generation costs using `record-cost` with explicit actual/estimate basis and evidence. This command records costs only; it never calls/pays a provider. Reservations, prior attempts and revisions all count toward the IDR 25,000 ceiling. Do not reset the production ID to evade the ceiling. Electricity is an estimate, not a metered bill or a complete labour/depreciation cost.
8. Only the human reviewer can run `egon-creative approve JOB_ID --by "Owner identity" --ack-human --ack-visual`. Approval binds the current input, output and canonical logo. Fixtures cannot be approved. This records approval locally and does not publish anything. This release has no Instagram publisher or verified posting connection.
9. After an independently authorised publication, import genuine performance exports using `egon-creative metrics JOB_ID observed-export.json`. Retain source/time/definitions. Missing data remains null; attributed sales need order/UTM evidence. This does not update the financial ledger.

Failures preserve attempt and cost history. Inspect `FAILURE.json` and logs, correct the underlying issue, and use `retry JOB_ID` only for FAILED/BLOCKED jobs. A crashed worker left RUNNING requires operator investigation; do not start duplicate jobs or silently release its reservation. This pilot does not include automatic stale-worker recovery or a daemon/scheduler installer.

Flow remains a manual brief/asset inbox. Inspect the actual account's terms, model, output count and credit cost before any generation; an upload rights agreement needs the human's acceptance. Generated media is never tagged as authentic footage. No Flow API, paid credits, automatic purchases or automatically composited Flow output are assumed.
