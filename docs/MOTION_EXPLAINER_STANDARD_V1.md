## Direction

- Build one beginner-friendly discovery per episode. Begin with the useful question or reveal, then show what happens and why it matters.
- Main objects and the process occupy the visual focus. Use a close-up, cutaway, purposeful transformation, comparison or process flow. A floating mascot is not sufficient motion design.
- Keep the original EGON character/brand identity consistent when used, but a guide need not dominate every shot. The owner-provided complete logo remains an unchanged canonical asset; honour its embedded colour profile for display.
- Aim for an informative visual beat every 2–4 seconds, with six to eight shots across a 30–60-second episode. Beat changes follow meaning, not arbitrary jump cuts. Camera moves point to the relevant part, rather than a permanent idle sine-wave pan.
- Use short caption groups, readable hierarchy and restrained emphasis. Animate group entry; do not pretend to have word-level alignment when only measured chunk timing is available. Preserve clear mobile safe areas.
- Voice and simple original SFX support the action. Default remains local Indonesian speech and FFmpeg. A vendor's voice-plugin recommendation does not enable paid API use in EGON.
- Explain schematic simplification honestly. Generic fruit, grinding and brewing illustrations are not photographs, real EGON tests, product demonstrations or universal recipes.
- Keep the same production ID across visual revisions and preserve the cumulative IDR 25,000 ceiling. A new animation of the same engineering lesson is not a new daily insight or evidence of audience learning.
